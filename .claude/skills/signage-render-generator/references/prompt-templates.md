## Prompt Modifiers Reference

### Time of Day Modifiers
| Time | Add to prompt |
|------|--------------|
| Golden Hour | `golden hour warm directional sunlight casting long shadows, warm color temperature` |
| Midday | `bright midday even overhead lighting, minimal shadows, clear sky` |
| Overcast | `overcast sky providing soft diffused illumination, even lighting without harsh shadows` |
| Dusk/Twilight | `blue hour twilight sky gradient from orange horizon to deep blue, sign illumination beginning to dominate` |
| Night | `full darkness, sign as primary light source, ambient urban lighting in background` |

### Camera Angle Modifiers
| Angle | Add to prompt |
|-------|--------------|
| Street Level | `shot from pedestrian eye level (1.6m height) at [X]m distance` |
| Slight Upward | `slight upward camera angle from street level, emphasizing sign height` |
| 3/4 View | `3/4 perspective angle showing both the sign face and its depth/projection` |
| Across Street | `viewed from across a [X]m wide road, full building and sign in frame` |
| Aerial/Drone | `aerial drone perspective at 45-degree downward angle, showing sign from above with surrounding context` |
| Driver View | `viewed from inside a vehicle approaching at [X]km/h, dashboard edge barely visible, realistic driving perspective` |

### Material Texture Modifiers
| Material | Add to prompt |
|----------|--------------|
| Brushed SS | `brushed stainless steel with visible horizontal grain direction, subtle reflections` |
| Painted MS | `mild steel painted in [COLOR] with smooth factory finish, visible welded joints` |
| Powder Coat | `powder-coated aluminium in [COLOR], smooth matte/satin finish with slight texture` |
| ACP Cladding | `aluminium composite panel cladding in [COLOR], flat smooth face with minimal visible joints` |
| Galvanised | `hot-dip galvanised steel with characteristic spangled zinc finish, silver-grey tone` |
| Corten | `weathering steel (Corten) with rich rust-brown patina, organic texture variation` |
| Granite Base | `polished [COLOR] granite cladding with visible natural stone veining` |

### Illumination Modifiers
| Type | Add to prompt |
|------|--------------|
| Front-lit | `front-lit by external spotlights mounted above, warm white light washing evenly across the sign face` |
| Back-lit (Halo) | `back-lit LED creating a soft halo glow on the wall behind each letter, letter faces appear as dark silhouettes` |
| Face-lit | `internally illuminated, light emanating through translucent acrylic letter faces, even [COLOR] glow` |
| Edge-lit | `edge-lit LED strips along letter perimeters creating a bright outline effect, letter faces dark` |
| Full LED Panel | `full-color LED panel displaying vivid digital content, individual pixels not visible at this distance` |
| Non-illuminated | `non-illuminated dimensional letters relying on ambient and natural light, visible material texture and shadows` |

### Indian Context Modifiers
| Context | Add to prompt |
|---------|--------------|
| Commercial Zone | `Indian commercial zone with mixed-use buildings, auto-rickshaws and motorcycles visible, Hindi/English signage on neighboring shops` |
| Highway | `Indian national highway setting, dual carriageway with truck traffic, flat terrain with sparse vegetation` |
| IT Park | `modern Indian IT park campus, glass-facade buildings, landscaped entrance with security booth` |
| Industrial | `Indian industrial area (MIDC/GIDC style), factory buildings with compound walls, wide service roads` |
| Mall/Retail | `Indian shopping mall exterior, modern architecture, busy parking area with mix of cars and two-wheelers` |
| Hospital | `Indian hospital campus entrance, wide approach road, ambulance bay visible, landscaped median` |

## Composite Prompts (Site Photo + Sign)

When the user provides an actual site photograph, use this pattern:

### Site Photo Composite Template
```
Using the uploaded photograph as the exact background scene and maintaining its exact perspective, lighting conditions, and architectural context, photorealistically add [SIGN_DESCRIPTION] to [LOCATION_ON_BUILDING]. The sign should appear naturally installed with:
- Correct perspective matching the building's vanishing points
- Shadows consistent with the existing light direction in the photograph
- Scale appropriate to the building — letters approximately [SIZE] relative to [REFERENCE_ELEMENT]
- [ILLUMINATION_TYPE] illumination matching the time of day shown
- Mounting hardware [VISIBLE/CONCEALED] with [BRACKET_DESC] attachment to the [FACADE_MATERIAL] surface
- Material finish: [FINISH_DESC]
The result should be indistinguishable from a real installation photograph.
```

### Multi-Sign Composite
```
Using the uploaded site photograph, add multiple signage elements:
1. [PRIMARY_SIGN_DESC] at [LOCATION_1]
2. [SECONDARY_SIGN_DESC] at [LOCATION_2]
3. [WAYFINDING_DESC] at [LOCATION_3]
All signs should share consistent [BRAND_STYLE] branding, with matching [FINISH] materials and [COLOR_SCHEME] color scheme. Maintain the photograph's exact perspective, lighting, and environment. Signs should appear as real installed elements with appropriate shadows, reflections, and scale.
```
