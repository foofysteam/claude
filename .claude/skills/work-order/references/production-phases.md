# Production Teams, Scope Templates & Handover Protocol

This reference defines the 5 production teams at Space Crafter Studio, their responsibilities,
the handover chain between them, and scope-of-work templates for common signage types.

---

## The 5 Production Teams

### 1. LASER CUTTING
**Colour code**: Blue (#1565C0)

**Core responsibilities:**
- Laser cutting acrylic sheets (faces, backing plates, decorative pieces)
- Laser cutting aluminium sheets (back plates, flat-cut letters)
- Laser cutting stainless steel (SS letters, logos)
- Precision cutting of intricate shapes (logos, complex scripts)
- Cutting aluminium channel strips to length for bending

**Materials they work with:**
- Acrylic (opal, clear, coloured) — 3mm to 8mm
- Aluminium sheet — 0.5mm to 2mm
- Stainless steel — 0.5mm to 1.2mm
- Aluminium channel stock (pre-cut to length before bending)

**Equipment:**
- CO2 laser cutter (for acrylic, wood, fabric)
- Fibre laser cutter (for metals — aluminium, SS, MS)
- CNC router (backup for thick acrylic, ACP)

**Quality checkpoints before handover:**
- All pieces cut to correct dimensions (±1mm tolerance)
- Edges clean, no burn marks on acrylic
- Each piece labelled with Element ID
- Protective film intact on both sides of acrylic
- Cut pieces match the nesting plan (sheet utilisation verified)

---

### 2. PRINTING & ROUTER CUTTING
**Colour code**: Orange (#E65100)

**Core responsibilities:**
- CNC router cutting of ACP panels (backdrops, sign boards, cladding)
- V-groove routing on ACP for folding/bending returns
- ACP contour profile cutting (organic shapes, curved profiles)
- Vinyl cutting (solid colours, text, graphics)
- Digital printing on vinyl, flex, SAV, fabric
- Lamination of printed materials
- Router cutting of PVC foam board

**Materials they work with:**
- ACP (Aluminium Composite Panel) — 3mm, 4mm
- PVC foam board — 3mm to 10mm
- Vinyl (cut, opaque, translucent, day-and-night)
- Flex banner (frontlit, backlit)
- SAV (self-adhesive vinyl)
- Fabric (dye-sublimation)
- Frost film

**Equipment:**
- CNC router (3-axis, for ACP/PVC/wood)
- V-groove router attachment
- Vinyl cutter/plotter
- Large format digital printer (eco-solvent/UV)
- Laminator

**Quality checkpoints before handover:**
- ACP panels cut to correct profile shape
- V-grooves at correct positions and depth (not cutting through back skin)
- Print colours match brand specifications
- Vinyl weeded cleanly, transfer tape applied
- Each panel/print labelled with Element ID or panel number

---

### 3. WELDING
**Colour code**: Red (#C62828)

**Core responsibilities:**
- MS (Mild Steel) frame fabrication — cutting, welding, grinding
- Channel letter assembly — bending channels to letter profiles, welding/riveting returns to back plates
- Stud welding for letter mounting
- Cleat and bracket fabrication for wall mounting
- Standoff/spacer fabrication and welding
- Pylon and totem structure fabrication
- ACP panel mounting onto MS frame (riveting, bolting)

**Materials they work with:**
- MS box section (various sizes — 2"×1", 1.5"×1.5", etc.)
- MS angle iron
- Aluminium channel (40mm, 60mm, 80mm — bent to letter profiles)
- Rivets, bolts, welding rods/wire
- Mounting hardware (cleats, L-brackets, rawl bolts)

**Equipment:**
- MIG welder (for MS)
- TIG welder (for SS, aluminium — precision work)
- Spot welder (for aluminium channel)
- Channel letter bending machine
- Angle grinder, bench grinder
- Drill press

**What they receive and from whom:**
- Laser-cut aluminium back plates and channel strips → from **Laser Cutting**
- Router-cut ACP panels → from **Printing & Router Cutting**

**Quality checkpoints before handover:**
- All welds ground smooth — no protrusions
- MS frame is square and flat (max 3mm deviation)
- Channel letters match template/printout profiles
- Wire entry holes drilled in back plates (Ø10mm)
- Standoffs at correct length and securely welded
- Each assembled piece labelled with Element ID

---

### 4. PAINTING
**Colour code**: Green (#2E7D32)

**Core responsibilities:**
- Surface preparation (sanding, degreasing, masking)
- Primer application (metal primer on MS, etching primer on aluminium)
- Anti-rust treatment on MS structures
- Automotive spray paint (2-3 coats)
- Powder coating (for indoor or high-durability applications)
- Duco paint (premium finish)
- Touch-up and edge finishing

**Materials they work with:**
- Automotive paint (spray cans and compressor-fed guns)
- Primer (metal primer, etching primer)
- Anti-rust primer
- Powder coat powder
- Masking tape, masking paper
- Thinner, isopropanol (for degreasing)

**What they receive and from whom:**
- Welded MS frames and channel letter assemblies → from **Welding**

**Painting sequence:**
1. Degrease all surfaces with isopropanol
2. Mask areas that should NOT be painted (face openings, mounting surfaces)
3. Apply primer — 1 coat, dry 2-4 hours
4. Apply colour coat 1 (mist coat) — dry 30 minutes
5. Apply colour coat 2 (full coverage) — dry 4-6 hours
6. Apply colour coat 3 if needed (deep colours like purple, red) — dry 4-6 hours
7. Remove masking
8. Inspect for runs, drips, bare spots — touch up

**Quality checkpoints before handover:**
- Even colour coverage, no bare spots
- No runs, drips, or orange peel
- Masking removed cleanly — no paint on face opening edges
- Paint fully cured (not tacky)
- Anti-rust on all MS surfaces (including hidden areas)
- Each piece labelled (label reapplied after painting if needed)

---

### 5. ASSEMBLY
**Colour code**: Purple (#6A1B9A)

**Core responsibilities:**
- LED module installation inside channel letters (type, colour, and quantity per element)
- LED strip installation (for side-lit letters, halo effects)
- Internal wiring of LED circuits within each letter
- SMPS mounting and wiring (input AC, output DC)
- Acrylic face fitting and bonding/sealing to channel
- Weatherproof sealing (silicone around all joints for outdoor signs)
- Mounting letters onto ACP backdrop (using standoffs)
- Full electrical connection and testing
- Final quality control and inspection
- Packing and dispatch preparation

**Materials they work with:**
- LED modules (must verify TYPE and COLOUR match the work order)
- LED strips (must verify COLOUR)
- SMPS units (verify wattage rating)
- Wire (1.5mm single core for internal, 2.5mm twin core for power feed)
- Connectors, cable glands, junction boxes, MCB
- Silicone sealant, acrylic solvent cement
- VHB tape, foam gasket tape
- Bubble wrap, foam sheets (for packing)

**What they receive and from whom:**
- Painted channel letter assemblies → from **Painting**
- Laser-cut acrylic faces (with protective film) → from **Laser Cutting** (held until painting is done)
- Painted MS frame with ACP panels mounted → from **Painting** (via Welding)
- Printed vinyl/graphics → from **Printing & Router Cutting** (if applicable)

**LED installation protocol (per element):**
1. Verify LED module/strip TYPE matches work order (Module vs Strip)
2. Verify LED COLOUR matches work order (Cool White vs Warm White vs Purple etc.)
3. Verify LED QUANTITY matches work order
4. Clean inside of painted channel with dry cloth
5. Mount modules with adhesive backing, maintaining consistent spacing
6. Solder/connect module chains — observe polarity
7. Route wires to exit through back plate hole
8. Label each wire pair with Element ID
9. Test before face fitting — all LEDs must illuminate evenly

**Quality checkpoints before dispatch:**
- All LEDs operational (no dead modules)
- Consistent brightness across each letter
- Correct colour temperature (no mismatched LEDs)
- Acrylic faces sealed weatherproof (outdoor signs)
- No visible hardware, screws, or wires from front viewing angle
- All letters level and evenly spaced
- SMPS units accessible for future maintenance
- Packing complete — each element labelled and protected

## Handover Protocol

### The Chain of Accountability

Every handover between teams must be explicit. This serves two purposes:
1. **Production tracking**: Management can see which team has the project right now
2. **Quality gates**: The receiving team inspects what they get before accepting

### Handover Flows by Signage Type

#### Front-Lit Channel Letters on ACP Backdrop (All 5 Teams)
```
START
  │
  ├──→ LASER CUTTING ──────────────────────────┐
  │    • Cut acrylic faces                      │
  │    • Cut aluminium back plates              │
  │    • Cut channel strips to length           │
  │                                             │
  ├──→ PRINTING & ROUTER CUTTING ──┐            │
  │    • Router-cut ACP panels     │            │
  │    • V-groove ACP returns      │            │
  │                                │            │
  │                     ┌──────────┘            │
  │                     ▼                       │
  │              WELDING                        │
  │              • Bend channels to letters     │
  │              • Weld channels to back plates │
  │              • Fabricate MS frame            │
  │              • Mount ACP on frame           │
  │                     │                       │
  │                     ▼                       │
  │              PAINTING                       │
  │              • Paint channels + frame       │
  │              • Anti-rust MS                 │
  │                     │                       │
  │                     ▼                       │
  │              ASSEMBLY ◀─────────────────────┘
  │              • Install LEDs (type + colour)
  │              • Fit acrylic faces
  │              • Wire + test
  │              • Mount on backdrop
  │              • QC + pack
  │                     │
  │                     ▼
  └──────────────── DISPATCH
```

#### Back-Lit / Halo Letters (No Printing)
```
LASER CUTTING → WELDING → PAINTING → ASSEMBLY → DISPATCH
```
(Printing & Router Cutting team is NOT involved unless there's a printed backdrop)

#### ACP Sign Board with Vinyl (No Laser, No Welding for letters)
```
PRINTING & ROUTER CUTTING → WELDING (frame only) → PAINTING (frame only) → ASSEMBLY → DISPATCH
```
(Laser Cutting NOT involved. Welding only for MS frame, not letters)

#### Vinyl-on-ACP Board (Minimal)
```
PRINTING & ROUTER CUTTING → ASSEMBLY → DISPATCH
```
(Only 2 teams — no Laser, no Welding, no Painting)

#### Neon Flex on Acrylic (Minimal)
```
LASER CUTTING → ASSEMBLY → DISPATCH
```
(Only 2 teams — Laser cuts the acrylic backing, Assembly mounts neon flex)

#### Pylon / Totem (Heavy Structure)
```
LASER CUTTING ──┐
                │
PRINTING & ROUTER ──→ WELDING → PAINTING → ASSEMBLY → DISPATCH
```
(All teams involved. Welding has the heaviest workload — MS structure + cladding)

## LED Specification Reminder

In every scope of work section that mentions LEDs (primarily the Assembly team), ALWAYS specify:

```
LED Type: Module (3-LED, 1.2W, 12V) or Strip (6mm, 12V) or Neon Flex (6mm)
LED Colour: Cool White 6500K / Pure White 5000K / Warm White 3000K / RGB / Purple / Red / Blue / Green
LED Quantity: [exact count per element]
```

Never write just "install LEDs" — always write "install [X] Cool White 6500K LED Modules (3-LED, 1.2W)" or similar.

This is because the inventory has multiple LED types and colours in stock. A vague instruction leads to the wrong LEDs being pulled and installed, which means rework.
