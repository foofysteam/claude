01 — Current Site Audit
Extracting the Existing Theme

Current Color Palette

Dark

White
Warm
Tan

Dominant dark/near-black backgrounds with warm off-white text. Secondary warm tan used for cards and highlights. No defined accent colour — CTAs use white on dark.

Current Typography

  • Headline: Serif display (thin weight)
  • Body: Clean sans-serif system font
  • Labels: Uppercase tracking, small size
  • No consistent type scale
  • Italic serif used for hero emphasis

Layout & Structure

  • Full-width video hero section
  • 6-step numbered process section
  • Industry grid (6 sectors)
  • Contact / free audit form (dark BG)
  • Shop products section
  • Customer testimonials carousel
  • Footer: 4-column grid with newsletter

Navigation

  • Sticky top nav with logo (image-based)
  • 7 primary links + dropdown Industries
  • No defined CTA button in nav
  • Dark background on scroll
  • Mobile hamburger menu

Overall Aesthetic Assessment

The current site leans into a dark, dramatic aesthetic that signals premium — but lacks a defined accent colour to drive conversions. The serif+sans pairing is strong. Key gaps: no button colour system, inconsistent section spacing, image-based logo limits font scalability. The new palette will bring warmth, approachability and a clear CTA colour (coral) while retaining sophistication.

Dark BG dominant Video hero Serif headlines No CTA accent Strong structure Needs: Accent colour Needs: Typography system

07 — Shopify Implementation
CSS Variable Map for Shopify Theme Editor

CSS Custom Properties — Add to theme.css

:root {
  /* SpaceCrafter Studio — Option 2 Palette */
  --color-background:      #F0EEE9;   /* Page background */
  --color-secondary-bg:    #D7CBC4;   /* Cards, borders */
  --color-foreground:      #222224;   /* All text */
  --color-accent:          #FA9A85;   /* Buttons, CTA */
  --color-accent-hover:    #f8836b;   /* Button hover */

  /* Typography */
  --font-heading-family:   'Garrett', Georgia, serif;
  --font-body-family:      'Telegraph', 'DM Sans', system-ui, sans-serif;
  --font-heading-weight:   300;
  --font-body-weight:      400;

  /* Spacing Scale */
  --spacing-xs:   8px;
  --spacing-sm:  16px;
  --spacing-md:  32px;
  --spacing-lg:  64px;
  --spacing-xl: 120px;

  /* Border */
  --border-radius-sm:  4px;
  --border-radius-md: 12px;
  --border-color:      #D7CBC4;
}
