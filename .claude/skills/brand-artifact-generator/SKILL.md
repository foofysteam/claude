# Brand Artifact Generator

## Purpose

Transform brand identity guidelines into comprehensive physical branding strategies with AI-ready prompts, technical specifications, and client presentation materials.

## Input Requirements

To use this skill effectively, provide:

1. Brand logo variations and guidelines
2. Color palette with hex codes
3. Typography specifications
4. Brand personality/archetype
5. Vision, mission, and tone of voice
6. Any existing brand materials or mood boards

## Output Deliverables

### 1. Brand Identity Analysis

Extract and document:

- Core brand identity (name, location, tagline)
- Brand archetype and personality traits
- Visual identity system (colors, typography, logo characteristics)
- Design language and signature elements
- Tone of voice positioning

### 2. Semantic Brand Translations

Create 3-4 strategic translations following this format:

**Brand Strategy → Design Cue → Physical Artifact**

Example:

- **Hero Spirit → Bold Geometric Forms**
  - Strategic Intent: Embody strength and determination
  - Design Cue: Sharp-edged shapes with strong horizontal lines
  - Artifact: 3D dimensional logo with deep relief
  - Rationale: Large-scale geometric forms communicate power and aspiration

### 3. Physical Branding Artifacts Catalog

Recommend 10-15 artifacts categorized as:

#### External Elements

- Monument/Pylon signage
- Building-mounted dimensional logos
- Window graphics
- Exterior wayfinding

#### Internal Elements

- Reception feature walls
- Wayfinding systems
- Feature murals
- Inspirational messaging
- Floor graphics
- LED/Neon signage
- Elevator wraps
- Specialty elements

### 4. Detailed Artifact Specifications

For each major artifact, provide:

**Structure:**

```
#### [Artifact Name]
**Concept:** [1-2 sentence description]

**Specifications:**
- Dimensions: [W × H × D]
- Materials: [Primary materials list]
- Colors: [Brand colors with hex codes]
- Lighting: [LED specifications if applicable]
- Placement: [Installation location and viewing distance]

**Design Details:**
- [Key fabrication details]
- [Mounting method]
- [Weather/durability considerations]
- [Special features]

**Estimated Timeline:** [Weeks for production + installation]
**Estimated Budget Range:** [Currency range]
```

### 5. AI Image Generation Prompts

Create 5-7 detailed prompts following this structure:

```
ARTIFACT: [Name]

PROMPT:
[Detailed scene description including: setting, artifact details, materials, colors with hex codes, lighting conditions, viewing angle, atmosphere, style]

NEGATIVE PROMPT:
[Elements to avoid: cluttered, dated, incorrect colors, low quality, etc.]

STYLE MODIFIERS:
- Camera: [lens, angle, composition]
- Lighting: [type, color temperature, mood]
- Quality: [resolution, realism level, style reference]

BRAND COLOR CODES:
Primary: [Hex] - [Name]
Secondary: [Hex] - [Name]
Accent: [Hex] - [Name]
```

### 6. Technical Specifications Summary Table

Create a master table with:

- Artifact name
- Dimensions
- Primary materials
- Complexity level (Low/Medium/High)
- Timeline (weeks)
- Estimated budget range

### 7. Client Presentation Structure

Provide a 20-slide Canva/PowerPoint outline:

1. Cover slide
2. Executive summary
3. Brand identity overview
4. Design philosophy/semantic translations
5. Artifacts overview grid
6. Individual artifact detail slides (6 key items)
7. Wayfinding system deep dive
8. Materials & finishes
9. Lighting strategy
10. Spatial experience journey
11. Implementation timeline (Gantt-style)
12. Investment summary
13. Case study (optional)
14. Why this approach works
15. Next steps & CTA
16. Thank you/contact

### 8. Brand Consistency Checklist

Ensure:

- ✅ Color accuracy (exact hex codes)
- ✅ Logo integrity (no distortion)
- ✅ Typography consistency
- ✅ Form language continuity
- ✅ Personality alignment
- ✅ Tone of voice matching
- ✅ Material quality standards
- ✅ Spatial coherence
- ✅ Accessibility compliance
- ✅ Durability ratings

## Process Guidelines

### Step 1: Analysis Phase

1. Review all brand materials thoroughly
2. Identify core visual and emotional themes
3. Extract exact specifications (colors, fonts, dimensions)
4. Understand brand archetype and personality

### Step 2: Strategic Translation

1. Map brand values to physical design language
2. Create 3-4 semantic translations
3. Ensure each translation has clear rationale

### Step 3: Artifact Selection

1. Consider facility type and user journey
2. Balance external visibility with internal experience
3. Include quick wins and signature pieces
4. Ensure comprehensive coverage (wayfinding, branding, inspiration)

### Step 4: Technical Development

1. Provide fabrication-ready specifications
2. Include material considerations for climate/usage
3. Specify mounting and installation methods
4. Note maintenance requirements

### Step 5: AI Prompt Creation

1. Write detailed, specific scene descriptions
2. Always include exact hex codes
3. Specify viewing angles and lighting
4. Add negative prompts to avoid common issues
5. Include style modifiers for consistency

### Step 6: Documentation

1. Create comprehensive technical tables
2. Develop clear presentation structure
3. Include visual references where possible
4. Provide implementation timeline

## Best Practices

### For Prompts

- Use exact brand color hex codes in every prompt
- Specify professional photography style (architectural, interior, etc.)
- Include lighting conditions (golden hour, LED illumination, etc.)
- Mention materials explicitly (brushed aluminum, vinyl, LED flex)
- Set appropriate resolution (8K, photorealistic)
- Use negative prompts to avoid common AI artifacts

### For Specifications

- Always use metric and imperial measurements
- Include weather-resistance for exterior elements
- Specify ADA compliance for accessibility
- Note maintenance and cleaning requirements
- Include power requirements for lit elements

### For Presentations

- Lead with visual impact (mockups, renders)
- Use minimal text on slides
- Show phased implementation approach
- Include realistic budget ranges
- Provide clear next steps

## Quality Standards

### Artifact Recommendations Must:

1. Align with brand personality and archetype
2. Be technically feasible and fabrication-ready
3. Consider user experience and wayfinding
4. Include accessibility considerations
5. Balance aesthetic impact with budget reality

### AI Prompts Must:

1. Generate accurate, on-brand visualizations
2. Include all critical specifications
3. Produce professional, client-ready mockups
4. Avoid copyright issues (no copying existing designs)
5. Be reproducible with consistent results

### Documentation Must:

1. Be comprehensive enough for vendor quoting
2. Include all relevant technical details
3. Present information clearly and professionally
4. Provide realistic timelines and budgets
5. Enable client decision-making

## Troubleshooting

**Issue:** AI prompts generating inconsistent results  
**Solution:** Add more specific material details, exact color codes, and tighter negative prompts

**Issue:** Budget estimates too high  
**Solution:** Prioritize quick wins, suggest phased implementation, offer material alternatives

**Issue:** Brand guidelines incomplete  
**Solution:** Ask clarifying questions, research similar brands, make documented assumptions

**Issue:** Technical specs insufficient for fabricators  
**Solution:** Add mounting details, material thickness, finish specifications, electrical requirements
