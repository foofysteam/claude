# Signage Types & Image Analysis Guide

Use this reference when analyzing uploaded signage design images to correctly identify
materials, fabrication methods, and LED types.

---

## Common Signage Types

### 1. Front-Lit Channel Letters
- **Look for**: 3D letters with illuminated face, opaque sides
- **Materials**: Aluminium channel returns (sides), acrylic face (opal/colored), LED modules inside
- **LED**: Modules behind the acrylic face → light shines forward
- **Depth**: Typically 40-60mm

### 2. Back-Lit / Halo-Lit Letters
- **Look for**: 3D letters with glow behind them (halo effect on wall)
- **Materials**: Aluminium or SS letter body (fully opaque), LED modules behind on spacers
- **LED**: Modules mounted on back plate, facing wall → creates halo glow
- **Depth**: 40-60mm + standoff spacers (20-40mm)

### 3. Front & Back-Lit Letters
- **Look for**: Letters that glow from front AND have halo behind
- **Materials**: Aluminium channel, acrylic face + LED on both sides
- **LED**: Modules inside (for face) + modules behind (for halo)
- **Most expensive illumination option**

### 4. Side-Lit / Edge-Lit Letters
- **Look for**: Thin letters with light visible from the edges, usually clear acrylic
- **Materials**: Clear acrylic letters, LED strips along edges
- **LED**: Strips (not modules) — ₹70/meter
- **Depth**: Usually thin, 10-20mm

### 5. Light Box
- **Look for**: Rectangular illuminated panel (can be backlit or edge-lit)
- **Materials**: Aluminium frame, acrylic or flex face, LED modules or strips inside
- **Variants**: Fabric light box, flex face light box, slim snap-frame light box
- **LED**: Modules for deep boxes, strips for slim boxes

### 6. ACP Cladding + Letters
- **Look for**: Large ACP panel background with letters mounted on top
- **Materials**: 4mm ACP sheets, letters on top (can be any type)
- **Structure**: MS frame behind ACP

### 7. Pylon / Totem
- **Look for**: Freestanding tall structure, often double-sided
- **Materials**: MS structure, ACP/SS cladding, light box or channel letters on top
- **Heavy structure work — factor in foundation, pylon fabrication**

### 8. Flex / Banner Signage
- **Look for**: Printed flexible material stretched on frame
- **Materials**: Flex print, MS/aluminium frame
- **Can be backlit (translucent flex) or non-lit**

### 9. Digital Print Signage
- **Look for**: Full-color printed graphics on substrate
- **Materials**: SAV (self-adhesive vinyl) on ACP, printed flex, printed acrylic
- **May include backlighting through translucent print**

### 10. Neon Flex
- **Look for**: Tube-like glowing lines (modern LED neon, not glass)
- **Materials**: Silicone neon flex LED, acrylic backing plate
- **Priced per running foot/meter of neon flex**

## Visual Identification Clues

| What You See | Likely Material | LED Type |
|-------------|----------------|----------|
| Glowing letter face, dark sides | Front-lit channel | Modules |
| Dark letter, wall glow behind | Back-lit / halo | Modules (behind) |
| Both face glow and wall glow | Front & back-lit | Modules (double) |
| Thin glowing edges, clear body | Side-lit / edge-lit | Strips |
| Large flat glowing panel | Light box | Modules or strips |
| Tube-like glowing lines | Neon flex | Neon flex LED |
| Printed graphics, no glow | Print signage | None or backlit |
| Metal letters, no glow | Non-illuminated | None |
| Tall freestanding structure | Pylon / totem | Various |

## Estimating Dimensions from Images

When exact dimensions aren't provided:
1. **Look for reference objects**: doors (standard 7ft height), people (~5.5ft), ceiling tiles (2×2 ft), bricks (9"×3")
2. **Standard storefront fascia**: typically 2-4 ft tall, 10-20 ft wide
3. **Reception signs**: typically 4-8 ft wide, 1-3 ft tall
4. **Pylon signs**: typically 8-20 ft tall, 3-6 ft wide
5. **Always flag estimated dimensions** and ask the user to confirm

## Common Combinations

| Signage Type | Typical Materials | Typical LED |
|-------------|-------------------|-------------|
| Retail storefront | ACP backdrop + front-lit channel letters | Grade B modules |
| Premium showroom | SS halo-lit letters on stone/ACP | Grade A modules |
| Hospital/Corporate | Acrylic front-lit + ACP backdrop | Grade A modules |
| Budget retail chain | Flex light box or ACP + vinyl | Grade C modules or strips |
| Restaurant/Cafe | Neon flex on acrylic | Neon flex LED |
| Wayfinding/Interior | Side-lit acrylic or vinyl on acrylic | Strips |
